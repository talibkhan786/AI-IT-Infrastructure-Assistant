# Roadmap

## Phase 1 — Starter (current)
- [x] CLI troubleshooting demo
- [x] Curated JSON knowledge base
- [x] Safe, advisory-only recommendations
- [x] Basic project documentation

## Phase 2 — Improve usability
- [ ] Add a web UI (FastAPI + simple frontend)
- [ ] Add categories, feedback, and search filters
- [ ] Add unit tests and CI with GitHub Actions

## Phase 3 — AI and retrieval
- [ ] Add optional LLM provider configuration using environment variables
- [ ] Implement RAG over approved SOPs and public documentation
- [ ] Display sources and confidence; distinguish sourced facts from suggestions

## Phase 4 — Operations integrations (only with authorization)
- [ ] Read-only inventory/monitoring integrations
- [ ] Role-based access and audit logging
- [ ] Approval workflow before any write action
- [ ] Secret management and data-retention controls

## Success measures
- Useful answer rate from user feedback
- Time saved on repeat support questions
- Knowledge-base coverage and freshness
- Zero unapproved production changes
